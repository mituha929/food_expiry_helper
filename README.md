# 食間管理大師

食間管理大師是一款用來記錄食物有效期限的 App，可協助使用者管理冰箱食材、暫存本機資料，並在食物即將到期時寄送 Email 提醒。

## APP 使用方法

### 登入與註冊

1. 開啟 App 後進入登入頁。
2. 若已有帳號，輸入 Email 與密碼後登入。
3. 若尚未有帳號，點選「還沒有帳號？點此註冊」建立新帳號。
4. 登入後即可使用雲端同步與 Email 提醒功能。

### 新增食物

1. 在首頁點選「新增食物」。
2. 輸入食物名稱。
3. 選擇有效日期。
4. 設定到期前幾天提醒。
5. 可選填條碼、金額與發票號碼。
6. 點選「確認儲存並同步」完成新增。

### 掃描商品條碼

1. 進入新增或修改食物頁面。
2. 在「條碼編號」欄位右側點選相機圖示。
3. 掃描商品條碼後，條碼會自動填入欄位。

### 掃描發票

1. 進入新增或修改食物頁面。
2. 在「發票號碼」欄位右側點選 QR Code 圖示。
3. 將發票 QR Code 對準掃描框。
4. 掃描成功後確認輸入，發票號碼會自動帶入欄位。

### 查看與管理食物

1. 首頁會顯示目前尚未過期的食物。
2. 可使用搜尋欄搜尋食物名稱。
3. 點選食物卡片可查看詳細資料。
4. 在詳細資料頁可點選「修改資訊」編輯食物。
5. 在清單中向左滑動食物卡片可刪除該筆資料，刪除後可在底部提示列點選「復原」。
6. 底部可切換「我的冰箱」與「已過期食物」。

### 本機暫存模式

1. 若尚未登入，可在登入頁點選「先新增本機食物」。
2. App 會提示目前資料只會暫存在本機，尚未同步前不會寄送 Email 提醒。
3. 本機暫存資料可新增、查看、修改與刪除。
4. 本機暫存資料不會啟用雲端同步與 Email 提醒。
5. 登入後若偵測到本機暫存資料，App 會詢問是否與雲端資料合併。

### 合併本機暫存資料

登入後若有本機暫存資料，App 會逐筆比對雲端資料。

若可能重複，使用者可選擇：

- 保留雲端
- 用本機覆蓋
- 新增為另一筆

### Email 到期提醒

登入後新增到雲端的食物，會依照設定的提醒天數寄送 Email 提醒。

例如食物有效日期為 `2026/07/20`，提醒天數設定為 `1`，系統會在到期前一天寄送提醒信。
